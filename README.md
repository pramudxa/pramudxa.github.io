## GitHub Pages
1. Create `YOUR-GITHUB-USERNAME.github.io`.
2. Upload the files.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Replace `YOUR-GITHUB-USERNAME` in `index.html`, `robots.txt`, and `sitemap.xml`.
